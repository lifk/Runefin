Runefin 0.2.0 is the HDR release.

**Proper HDR output.** A 16-bit floating-point surface in linear sRGB (`Rgba16Float` +
`ExtendedSrgbLinear`, scRGB) when the compositor advertises one, with interface white at
203 cd/m² (BT.2408) and absolute PQ/HLG video luminance; a plain SDR surface otherwise. Settings
switches it at runtime and reports what the surface actually accepted (`Active`, `Unsupported`,
`Failed`, `Off`). Nothing is tone-mapped while claiming to be HDR, and no display is asked for a
format it did not advertise.

**Deep links.** `runefin://item/<id>` and `runefin://play/<id>` open the detail page or start
playback in the running player; a second launch forwards to the first, sign-in is deferred until
there is a session, and nothing interrupts something already playing. The scheme is registered in
the desktop entry used by the Steam tile.

**Optional Decky companion.** `scripts/steam-install.py --decky` copies a Quick Access Menu plugin
(open, transport, quit, a Media collection) when Decky Loader is already installed. Decky is never
installed or assumed, the plugin takes no root flag and makes no HDR claim; the bridge is MPRIS
plus the deep links.

**Trickplay.** The tile under the playhead is fetched when the player's chrome appears, a moving
pointer no longer queues a sprite per sixteen minutes crossed, the panel keeps its size and shows
the time while a tile loads, and it grows to 320×180 when the server publishes a 960 px or wider
set. The decoded-image cache and the disk cache are bounded by bytes, so one large sprite cannot
evict a library's art, and a sprite too large to decode (1280 in 10×10, 368 MB) is refused instead
of loaded.

## Install

```sh
flatpak remote-add --if-not-exists --user runefin https://lifk.github.io/Runefin/runefin.flatpakrepo
flatpak install --user runefin io.github.lifk.Runefin
```

Or the offline bundle attached to this release:

```sh
flatpak install --user ./Runefin-0.2.0-x86_64.flatpak
```

Steam tile, artwork and the optional QAM plugin: `python3 scripts/steam-install.py` (see
`packaging/steam/README.md`).

HDR needs a compositor that advertises an HDR format (KWin on Wayland in Desktop Mode); SteamOS
Gaming Mode does not offer one to a native Flatpak, so the app stays SDR there.
