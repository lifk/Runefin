Runefin 0.3.2 adds **three real SteamOS sessions** — Desktop, Gaming and Media — with a
one-command installer, and keeps Desktop as the stock Plasma desktop.

**Media is a session, not an app over Desktop.** Desktop Mode runs stock
`startplasma-wayland` with no Runefin process and no autostart. Gaming runs stock Steam through
`gamescope-session`. Media runs KWin with Runefin full screen and no Plasma behind it, so HDR,
input and the app are the whole picture.

**One install command.** In Desktop Mode, with Steam running and signed in once:

```sh
curl -fsSLO https://raw.githubusercontent.com/lifk/Runefin/main/scripts/steam-install.py
python3 steam-install.py --three-modes --default-mode media
```

It installs the Flatpak and Steam tile, writes the mode dispatcher and supervisor under
`~/.local/share/runefin/modes`, installs `runefin-mode` in `~/.local/bin`, and asks `pkexec` once
for the single `/etc/sddm.conf.d/zzz-runefin-modes.conf` drop-in. There is no pin unit, no daemon
and no root process after install. `--default-mode desktop` (the default) boots stock Plasma;
`game` boots Steam; `media` boots Runefin. Reboot, or run `runefin-mode media` to switch now.

**Switching.** With the drop-in installed, the Steam **Runefin** tile now switches Gaming to
Media instead of launching an app inside gamescope. From Media, **Settings → SteamOS modes** has
**Switch to desktop**, **Switch to game** and **Restart app**. On Desktop, the **Runefin Media**
and **Runefin Game** entries cover the other direction. `runefin-mode media|desktop|game` is the
same transaction from a shell.

**Failure has a floor.** Media writes a first-frame marker; the supervisor restarts a crash and,
after three failures, writes `desktop` and exits. A KWin failure before the app starts is caught
by the next session start. From a TTY, `runefin-mode desktop` is the recovery. A failed session
lands in Plasma, not a black screen.

**Support commands.** `runefin-mode status` prints the mode, session, drop-in and app version;
`runefin-mode repair` re-writes the drop-in after a SteamOS update; `runefin-mode restore`
removes the drop-in and returns stock autologin. The drop-in is additive, so removing it reveals
SteamOS's own configuration; no Valve file is edited.

**Known limits.** Steam's own **Switch to Desktop** is best-effort because our SDDM session owns
the login; use the tile, the desktop entries or the Settings page. There is no sync service for
Steam's native switch yet. The SDDM/KWin/Steam Machine sequence is the next hardware pass; this
build is the one to test it on. The keyboard covers ASCII URLs, passwords and search; a full IME
is still later.

**Everything from 0.3.1 carries over**: the in-app on-screen keyboard, downloads and offline
playback, virtualized Home rails, `runefin://` links, the optional Decky Quick Access Menu
companion, trickplay previews and scRGB HDR with its SDR fallback.

## Install

```sh
flatpak remote-add --if-not-exists --user runefin https://lifk.github.io/Runefin/runefin.flatpakrepo
flatpak install --user runefin io.github.lifk.Runefin
```

Or the offline bundle attached to this release:

```sh
flatpak install --user ./Runefin-0.3.2-x86_64.flatpak
```

HDR needs a compositor that advertises an HDR format (KWin on Wayland in Desktop or Media); SteamOS
Gaming Mode does not offer one to a native Flatpak, so the app stays SDR there.
