Runefin 0.2.1 is a cold-start release.

**A quarter of the launch is gone.** The first frame used to register the math fallback faces —
Noto Sans Math, Noto Music and Symbola — to draw the checkmark in the sidebar, because the UI
loaded them for any symbol block, whether or not the app's own font already drew the glyph. They
now load only for a symbol the app cannot draw and for real math alphanumerics, which changes
nothing on screen: launch to first frame measured 103.5 ms before and 78.3 ms after on this
machine. The arrow that a detail button draws from those faces still does.

Everything from 0.2.0 is unchanged: proper scRGB HDR output with an SDR fallback, `runefin://`
deep links with single-instance forwarding, the optional Decky Quick Access Menu companion
(`scripts/steam-install.py --decky`), and the trickplay preview work.

## Install

```sh
flatpak remote-add --if-not-exists --user runefin https://lifk.github.io/Runefin/runefin.flatpakrepo
flatpak install --user runefin io.github.lifk.Runefin
```

Or the offline bundle attached to this release:

```sh
flatpak install --user ./Runefin-0.2.1-x86_64.flatpak
```

HDR needs a compositor that advertises an HDR format (KWin on Wayland in Desktop Mode); SteamOS
Gaming Mode does not offer one to a native Flatpak, so the app stays SDR there.
