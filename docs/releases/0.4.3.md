Runefin 0.4.3 brings back the Home billboard on upgrade, gives libraries a background and fixes
the first grid row's focus ring.

**Home billboard.** The old configuration saved the compact header as `home_hero = false`, so the
Nocturne Home opened without its hero. A one-time layout migration turns the billboard on and
stores a layout revision; turning it Off in Settings afterwards is kept. The billboard is the
first non-hidden **Continue Watching** item, so the backdrop is deterministic rather than random;
when there is no resume it falls back to the first item of the newest rail. Its backdrop also
tints the ambient behind Home.

**Library background.** A library has no backdrop of its own, so it used to be flat black. It now
has the same graphite top band as Home over the full height, plus a cool radial wash in the upper
right; the poster wall remains the subject.

**First grid row.** The 1.05 focus scale and the 2 pt ring had no room at the top of the scroll
viewport, so the top row's ring did not match the card. The grid and list now start 10 pt inside
the viewport; the focused card and its screen-level ring are complete.

`scripts/check.sh` is green: 508 app tests (27 ignored), workspace clippy, guardrails and the
release build. CI builds and signs the Flatpak.
