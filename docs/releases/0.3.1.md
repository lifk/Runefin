Runefin 0.3.1 adds an in-app on-screen keyboard for Big Screen, so a remote or gamepad can set
up a server, search and change settings without the Steam overlay keyboard.

**The keyboard.** Focusing a text field on a big screen opens a bottom sheet with QWERTY, shift,
digits and symbols, space, backspace, Enter, Next and Hide. Every key is a normal focus target:
the D-pad moves, **A** types, **B**/Back hides, and a CEC remote's **OK** works as well as a pad.
The sheet edits the field directly, so it does not depend on Steam's overlay injection, and it is
the same keyboard on the Steam tile, a Desktop window with a remote, and the future Media mode.

**Passwords and search.** Secure fields show a masked value and a temporary **Show** toggle that
resets when the sheet closes. Typing into Search, Library search, Settings search or Seerr search
runs the same debounced change hook a physical keyboard would. The connect form has a **Next**
key that moves from Server to Username to Password, so the first machine setup is possible with no
keyboard at all.

**Choose when it opens.** Settings → Interface → **On-screen keyboard** has **Auto** (open when a
text field takes focus in Big Screen), **On demand** (Menu/Start on a field) and **Off**. Auto is
the default; Desktop Mode is unchanged and does not open the sheet on focus.

**What this does not do.** The three-mode SteamOS session (Desktop, Gaming, Media) is a written
plan, not installed by this build. The keyboard covers ASCII URLs, passwords and search; a full
IME is a later decision. Real Steam Machine remote/CEC validation is still the hardware pass.

**Everything from 0.3.0 carries over**: downloads and offline playback, virtualized Home rails,
scRGB HDR output with its SDR fallback, `runefin://` links, the optional Decky Quick Access Menu
companion, trickplay previews and true hairlines.

## Install

```sh
flatpak remote-add --if-not-exists --user runefin https://lifk.github.io/Runefin/runefin.flatpakrepo
flatpak install --user runefin io.github.lifk.Runefin
```

Or the offline bundle attached to this release:

```sh
flatpak install --user ./Runefin-0.3.1-x86_64.flatpak
```

HDR needs a compositor that advertises an HDR format (KWin on Wayland in Desktop Mode); SteamOS
Gaming Mode does not offer one to a native Flatpak, so the app stays SDR there.
